# Guide Images

This directory contains guide images for the TrendyMirror application.

In a production environment, these would be actual guide images. For development purposes, you should replace these placeholder files with real images.

## Required Images:

1. `model_guide.jpg` - An image showing the requirements for model images
2. `garment_guide.jpg` - An image showing the requirements for garment images

Please ensure all images are properly licensed for use in your application.
